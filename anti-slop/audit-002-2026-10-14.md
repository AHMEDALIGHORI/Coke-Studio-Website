## Findings

### MEDIUM (Purpose-Gate / craft)

19. **R-05 / C-3 (archive browsing is still mostly linear).** The Catalog offers era filters, but there is no way to search or jump by title, artist, or season. For a tribute archive with many tracks, a visitor who arrives looking for one performance must scan the generated list. Fix: add a compact, keyboard-accessible title/artist search beside the existing era filters, with an honest empty result state. This would turn the catalog from a beautiful index into a useful archive without adding a template section.

20. **R-14 / R-05 (the visual archive repeats one dominant composition).** All four gallery pieces use the same full-bleed image, bottom gradient, tag, title, and description treatment. The wide/narrow alternation helps the grid, but the content hierarchy is still identical. Fix: give one still a different editorial role, such as a quieter instrument plate with caption-first treatment, while keeping the existing lightbox behavior.

21. **R-13 (ambient soundscape is visually louder than its role).** The fixed soundscape control combines blur, shadow, pill geometry, animated spectrum bars, and a persistent bottom-corner position. The generator is a nice optional layer, but its treatment competes with the tribute content on small screens. Fix: reduce it to a quieter compact control after activation, reserve the expanded label for hover/focus, and add page bottom padding so it never sits over the final CTA or source text.

22. **R-27 / C-4 (external library failure is not isolated).** `app.js` calls `gsap.registerPlugin(ScrollTrigger)` at startup. If either CDN library is blocked or unavailable, the whole script can stop before injected content, navigation, and fallback interactions initialise. Fix: guard the animation bootstrap and provide a plain-scroll path that still renders the data, links, filters, modal, and mobile menu when animation libraries are unavailable.

### LOW (Quality Locks)

23. **R-35 (verification scripts disagree on the local port).** `test/smoke.js` targets `localhost:5173`, while `test/verify_masterpiece.js` targets `localhost:3000`; the package start script delegates to `server.js`. Fix: centralise the test base URL or have both scripts read the server's configured port, so the delivery gate can be rerun without guessing which server is active.

24. **R-32 (lightbox focus containment is incomplete).** The lightbox moves focus to its close button and restores it, but it does not trap Tab inside the dialog the way the video modal does. Keyboard users can tab into page content behind the open lightbox. Fix: add the same small focus loop used by the video dialog, including Shift+Tab and Escape behavior.
