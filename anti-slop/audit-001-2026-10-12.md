## Findings (numbered; priority = rule tier)

### HIGH (Hard Gate)

1. **R-02 (em dashes).** 29 user-facing em dashes: all four section kickers ("01 — The Hall of Fame" x4), `<title>`, meta description, poster caption (2), quote attribution, "Pakistan · 2008 — 2026", alt text in `index.html`; blurbs + era notes in `data.js` (19). Em dash is the single most reliable AI tell; R-02 bans it outright. Fix: rewire each to period/comma/colon/parenthesis (kickers become "01 · The Hall of Fame").
2. **R-25 (low-contrast small text).** `--muted-2` #6c6862 fails AA 4.5:1 everywhere it is used: 3.63:1 on void, 3.50 on stage, 3.33 on stage-2, 3.12 on stage-3 (computed). Used by: scroll hint, stat notes, loader %, "Est. 2008", track season/year, era seasons, "YouTube views" label, disclaimer, modal tags. Fix: lighten `--muted-2` to a verified ≥4.5:1 value (target ~#8a857e; verify before shipping).
3. **R-25 / WCAG 1.4.11 (play icon on hover).** White play icon on the hover fill fails non-text 3:1 on three of four anthem accents: Tajdar gold #d4af37 = 2.10:1, Chaap sage #9db4a0 = 2.22:1, Afreen gold #c8a24a = 2.41:1 (Pasoori red 4.49:1 passes). Fix: darken those accents for the hover fill, or use a near-black icon on light accents.
4. **R-03 (mobile navigation).** Below 720px the nav links are `display:none` with no menu replacement: phones have zero section navigation. Between 721-860px the 12px links are ~26px-tall tap targets, under the 44px minimum. Fix: labelled mobile menu or compact bottom nav; enlarge tap area.
5. **R-35 (never actually run).** Verification so far = static-server HTTP 200s + code inspection only. No browser click-through of controls, keyboard path, modal, or mobile breakpoints has been recorded. Fix (in fix phase): headless-browser click-through with a recorded element-by-element report.
6. **R-27 (player states).** The modal's YouTube iframe has no loading state and no error state: a blocked embed or offline player shows a black box with no cause and no next action. Fix: loading label + error message ("Video could not load. Watch it directly on YouTube" with the verified link).
7. **R-36 (staccato drama / aphorism in hero copy).** "One microphone. One take. Infinite soul." is a staccato run; "Atif. Rahat. Abida. Ali Sethi. Momina. The list is a country." is a name-run ending in an aphorism. Both are engineered-rhythm patterns from the copywriting skill. Fix: rewrite keeping the voice (one emphatic sentence allowed; drop the run).


### MEDIUM (Purpose-Gate; reason must be written or small change)

8. **R-06 (Inter on the AI-default list).** Inter is explicitly named as a model-default typeface; it carries all small UI text. Fix: write the brand-character reason (neutral grotesque defers all personality to Bodoni Moda) or replace with a non-default UI sans.
9. **R-37 / R-31 (no DESIGN.md).** Direction lives only in this conversation. Fix: write `DESIGN.md` holding the dials, palette/type reasons, and one-line reasons for film, marquee, grain, cursor, poster block, seals (this resolves the "written reason" half of findings 10-15 and 18).

11. **R-19 (endless marquee loop).** The ticker loops forever (speed reactive to scroll, respects reduced-motion). Fix: write its purpose in DESIGN.md (a living setlist board, the show's constant pulse).
12. **R-09 / R-14 (capsules + uniform grid).** Season/genre/duration tags and era marks are real labels; the catalog grid is uniform. Fix: write the reasons (functional metadata labels; archive index uniformity, hierarchy carried by the featured poster above).
13. **R-17 (sourcing not visible).** All numbers are real (see fact base) but nothing on the page cites sources. Fix: footer sources line (Wikipedia, YouTube/socialcounts Oct 2026); refine attribution to "Bhaskar Kashyap, The Express Tribune, July 2010".
14. **R-08 (CTA arrow).** The arrow on "Visit the official channel" needs its written purpose (directional cue marking an external action). Fix: DESIGN.md.
15. **R-01 / R-12 / R-13 (doses within caps, reasons unwritten).** Progress-bar glow (1 element), loader seal pulse (1), poster + modal shadows (2), keyart scrim (functional). All within caps. Fix: reasons into DESIGN.md with finding 9.
